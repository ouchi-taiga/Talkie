# 要件定義書：SNS風・自作チャット小説メーカー（仮）

## 1. アプリ概要

ユーザーがスマホのメッセージアプリ（LINE風）のような会話シナリオを作成し、リアルタイムでプレビュー・画像保存・アニメーション再生ができるWeb/Appツール。

* **想定ユーザー:** SNS（TikTok, Instagram Shorts, X）にチャット風動画・画像を投稿したいクリエイター、暇つぶしWebユーザー
* **プラットフォーム:** Web (SvelteKit) ＋ 将来的なiOS/Androidアプリ化 (Capacitor)
* **開発コンセプト:** ローカルLLM（Qwen2.5-Coder等）をAIエージェントとして活用し、開発コスト・通信コストゼロで構築する。

---

## 2. コア機能要件（MVP: 最小限の製品）

### ① キャラクター管理機能

* キャラクターの追加・編集・削除
* プロフィール設定（名前、アイコン画像、吹き出しの色）
* 登場人物（自分 / 相手）の割り当て切り替え

### ② チャットエディタ機能

* 発言の追加・編集・削除・並べ替え（ドラッグ＆ドロップまたは上下ボタン）
* 発言タイプ切り替え：
  * メッセージ（送信 / 受信）
  * 画像添付
  * 既読表示オン/オフ
  * システムメッセージ（「〇〇が退室しました」等）
* リアルタイムプレビュー（入力した内容がそのままLINE風画面に即時反映）

### ③ 出力・シェア機能

* **画像書き出し:** 作成したチャット画面全体（または指定した範囲）を1枚の長尺画像（PNG）としてダウンロード（`html-to-image` 等のライブラリ使用）
* **再生モード:** 画面をタップするごとに1発言ずつポコポコ表示されるプレゼン/閲覧モード

---

## 3. 非機能要件・制約事項

* **パフォーマンス:** メッセージ入力時、プレビュー画面が遅延なくミリ秒単位でリアルタイム更新されること。
* **データ保存:** 作成途中のデータはブラウザの `localStorage` に自動保存され、ページを閉じても消えないこと（バックエンドサーバー不要の設計）。
* **完全無料運用:** サーバー通信を発生させず、完全にクライアントサイド（JavaScript / Wasm）のみで完結させること。

---

## 4. 技術スタック

* **フロントエンド:** SvelteKit (Svelte 5 / Runes 利用推奨)
* **CSSフレームワーク:** Tailwind CSS + DaisyUI
* **アプリ化 (Future):** Capacitor
* **画像生成:** `html-to-image` または `html2canvas`
* **ローカル開発環境:** Node.js, Vite, Ollama (Qwen2.5-Coder-14B / Qwen3.6)
